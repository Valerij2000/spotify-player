# Мой плеер

Личный веб-плеер для организации embed-блоков Spotify: вставляете ссылку на
трек/альбом/плейлист — он добавляется в вашу библиотеку (хранится в
`localStorage` браузера) и воспроизводится через официальный iframe-виджет
Spotify.

Важно: этот инструмент не убирает рекламу и ограничения самого Spotify —
он лишь упорядочивает embed-блоки. Что видит и слышит пользователь внутри
плеера, зависит от его собственной учётной записи Spotify (Free/Premium),
как и в любом другом сайте с embed-плеером.

## Стек

- Vite (vanilla JS шаблон)
- HTML5 / CSS3 (Flexbox + Grid, CSS-переменные)
- Vanilla JavaScript (ES6+, модули, делегирование событий)
- Без сторонних UI-фреймворков

## Установка и запуск

```bash
npm install
npm run dev       # локальный сервер разработки
npm run build      # сборка в dist/
npm run preview    # предпросмотр собранной версии
```

## Структура

```
index.html            # разметка приложения
style.css              # стили (импортируется в main.js)
main.js                 # точка входа
src/js/app.js           # UI-логика: рендер, обработчики событий
src/js/embed.js         # парсинг ссылок/embed-кода Spotify, сборка embed-URL
src/js/store.js          # персистентность в localStorage
```

## Как добавить трек

Вставьте в поле «Добавить» один из вариантов:

- обычную ссылку: `https://open.spotify.com/track/01KI89g5QoUHP0ldfl2Y1G`
- embed-ссылку: `https://open.spotify.com/embed/track/01KI89g5QoUHP0ldfl2Y1G`
- весь HTML-код `<iframe>`, скопированный из Spotify → Поделиться → Embed track

Поддерживаются типы: трек, альбом, плейлист, эпизод, подкаст.

Название трека плеер пытается подтянуть автоматически через публичный
oEmbed Spotify; если это не удалось (например, нет сети), название можно
задать вручную через значок ✎ на карточке трека.

Библиотеку можно выгрузить в JSON-файл (кнопка «Экспорт») и загрузить
обратно на другом устройстве (кнопка «Импорт»).
